# AI People Team for Tremendous

An interactive, personal demo of an AI People Team built for the People Operations Manager role at Tremendous. Ten agents cover the employee lifecycle (onboarding, offboarding, benefits, payroll, engagement, immigration, leave, compliance, AskPeople and insights), each tailored to the job description. The page also shows how the agents work with Slack, Notion, Google Workspace, an HRIS, Zapier and n8n, with a click-through sample.

**Personal build, not deployed.** This is not Tremendous's system and is not endorsed by Tremendous. It uses sample content only, with no real employee data. Screens in the demo are generic samples, not any vendor's real interface.

## View it

Open `index.html` in a browser. It is a single self-contained file with no build step.

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Upload `index.html`, `.nojekyll` and `README.md` (Add file, then Upload files), and commit to `main`.
3. Go to Settings, then Pages, choose "Deploy from a branch", select `main` and `/ (root)`, and save.
4. Your page will be live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.
